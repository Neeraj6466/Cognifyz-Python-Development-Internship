
Project: Number Guesser

Level: 2
Task: 2

Description:
This project is a number guessing game.
The user enters a minimum and maximum number.
The computer generates a random number
within that range.

Features:
1. User can select the number range.
2. Computer generates a random number.
3. Displays Too High or Too Low hints.
4. Game ends when the correct number is guessed.

Python Concepts:
1. Random Module
2. Variables
3. If-Else Conditions
4. While Loop
5. User Input
